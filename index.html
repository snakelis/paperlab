PAPERLAB · AGENT TOOLS

AI / MCP 接入

让 AI 写好 Markdown 和本地图片，再由 PaperLab 生成带排版与图片的 Word 文档。

接入方式：本机 stdio

先在 AI 客户端所在的电脑或运行环境安装工具，再由客户端启动 MCP 进程。当前网页地址不是远程 MCP 服务地址，不需要 API Key；浏览器里的草稿不会自动同步给 Agent。

1. 安装工具

准备 Node.js 20+、Git 与 pnpm 10.32.1。在终端执行以下命令，完整安装依赖（请勿使用 --prod），并安装导出需要的 Chromium。

安装命令
git clone https://github.com/snakelis/paperlab.git
cd paperlab
pnpm install --frozen-lockfile
pnpm exec playwright install chromium

另建一个已存在的文章工作目录，例如 article-workspace，放入 wallet.md 与 images/wallet.png。正文引用图片写作 ![图片说明](images/wallet.png "图注")；图片路径相对于文稿所在目录。

2. 配置 MCP 客户端

将以下配置加入客户端的 MCP 配置，替换两处绝对路径。外层配置字段以所用客户端要求为准；Windows 路径可写为 C:/tools/paperlab/scripts/mcp.mjs，不要混用 Windows 与 WSL 路径。

通用客户端配置
{
  "mcpServers": {
    "paperlab": {
      "command": "node",
      "args": [
        "/absolute/path/to/paperlab/scripts/mcp.mjs",
        "--workspace",
        "/absolute/path/to/article-workspace"
      ]
    }
  }
}

客户端会启动以下进程并连接其输入输出，无需启动编辑网页。请直接使用 node，避免包管理器的提示混入协议输出。

MCP 启动命令
node /absolute/path/to/paperlab/scripts/mcp.mjs --workspace /absolute/path/to/article-workspace

3. 让 AI 调用工具

list_layout_styles
参数为 {}，查询主题、颜色、字体和排版参数。先查询，再选择配置。
format_article
读取工作目录中已有的 Markdown 和图片，生成完整 DOCX。调用参数示例如下。
format_article 参数
{
  "input": "wallet.md",
  "title": "钱包入门",
  "config": {
    "theme": "bold",
    "accent": "violet",
    "fontSize": "18",
    "caption": "title",
    "captionFormat": "numbered"
  }
}

input 必填，使用工作目录内的 .md 或 .markdown 相对路径；title、config 可省略。字号、行距与宽度等数值参数使用字符串。

页面的「保存 AI 配置」导出的是排版 JSON，可作为这里的 config 使用，里面不包含正文、图片或 MCP 连接信息。

可直接交给 AI 的指令
在指定工作目录准备好 Markdown 文稿和本地图片。先调用 PaperLab 的 list_layout_styles 查询支持的排版，再调用 format_article 生成含图 DOCX。检查返回 ok=true，并保留 artifact.absolutePath、sha256 和实际 config。失败时报告 error，不伪造文件路径，不上传或发表文章。

4. 读取生成结果

成功返回 ok: true，文件位于工作目录的 .paperlab-output/<id>/article.docx，同目录包含 layout.json 与 manifest.json。

artifact.absolutePath 是运行主机上的文件路径，bytes 是文件大小，sha256 用于核验文件；它们不是公网下载地址或业务系统素材 ID。

失败返回 ok: false 与 error.code/message，MCP 另带 isError: true。遇到 BUSY 等待上次任务完成后重试；图片缺失或损坏会阻止导出。

文稿限 2 MB，单张图片限 5 MB、2400 万像素；支持 PNG、JPEG、WebP、GIF。图片需位于文稿目录或其子目录；Agent 导出不读取网络图片，请先准备本地文件。工具不改写正文，不上传、审批或发布文章。

不使用 MCP？通过 JSON 命令行调用

在插件目录新建 request.json，顶层用 name 和 arguments 包装工具名与参数：

request.json
{
  "name": "format_article",
  "arguments": {
    "input": "wallet.md",
    "title": "钱包入门",
    "config": { "theme": "bold", "accent": "violet" }
  }
}
执行命令
node scripts/agent.mjs --workspace /absolute/path/to/article-workspace --request request.json

成功退出码为 0，失败为 1，标准输出为 JSON；不传 --request 时从 stdin 读取单个请求。
